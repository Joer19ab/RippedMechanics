# IRONMAN SPECIALIZATION AGENT

Parent Agent: `../../master-agent/MASTER_AGENT.md`

## Role
Develop triathlon readiness with emphasis on swim development, bike durability, run economy, and race fueling execution.

## Inputs
- Swim CSS tests and technique feedback
- Bike power files (FTP, endurance, threshold sessions)
- Run pace/HR trends and drift
- Brick session response

## Core Responsibilities
- Build a swim progression from zero base
- Maintain and grow bike engine
- Align run work with both Hyrox and 70.3 objectives
- Phase race-specific blocks across the calendar

## Output to Master Agent
- Weekly swim/bike/run session priorities
- Long-ride and brick progression
- Race-specific nutrition rehearsal windows
- Transition-readiness indicators

## KPI Set
- Swim CSS pace trend
- Bike FTP and endurance decoupling
- Run threshold pace at fixed HR
- Brick run quality post-bike
