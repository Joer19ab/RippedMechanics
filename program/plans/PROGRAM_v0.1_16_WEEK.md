# PROGRAM v0.1 (16-Week Hyrox Build + 70.3 Base)

## Macrocycle Phases
1. Weeks 1-4: Foundation and diagnostics
2. Weeks 5-8: Build capacity and strength endurance
3. Weeks 9-12: Hyrox specificity and compromised running
4. Weeks 13-15: Sharpen and race simulation
5. Week 16: Taper and race

## Weekly Session Template (12 Sessions)
- Monday AM: Easy run Z2 + strides
- Monday PM: Lower strength + sled patterns
- Tuesday AM: Swim technique/aerobic
- Tuesday PM: Bike threshold
- Wednesday AM: Hyrox engine intervals
- Wednesday PM: Mobility + trunk + breathing
- Thursday AM: Swim technique + pull focus
- Thursday PM: Run threshold/tempo
- Friday AM: Easy bike Z2
- Friday PM: Hyrox strength endurance circuit
- Saturday: Long bike or brick
- Sunday: Long run Z2 + mobility

## Intensity Distribution
- Approximate 80/20 easy/hard split
- Key intensity days: Tue, Thu, Fri PM, selected Sat

## Mandatory Week 1 Testing
- Run 5K test
- Bike 20-min test (or ramp)
- Swim CSS test (400/200)
- SkiErg 1K
- Row 1K
- Sled push/pull timed efforts
- Farmer carry benchmark
- Sandbag lunge benchmark
- Wall ball benchmark

## Nutrition Day Types
- Light day: 280-360 g carbs
- Moderate day: 380-500 g carbs
- Heavy day: 500-700 g carbs
- Protein: 190-210 g/day
- Fat: 65-90 g/day

## Adaptation Rules
- Progress load only when compliance + recovery support it
- Deload every 4th week unless race/test constraint applies
- Protect sleep consistency as a performance input, not a lifestyle extra

## Success Criteria for v0.1
- >=90% completion rate
- All baseline tests collected
- Stable recovery markers
- No avoidable missed sessions due to planning failures
