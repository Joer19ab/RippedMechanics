# Success Operating System (High-Probability Execution)

## Mission
Maximize race outcome probability by enforcing consistent execution, fast feedback loops, and immediate corrective action.

## Outcome Targets
- Hyrox first race: sub-75 in 4 months
- 70.3 race: sub-5 on 2027-06-22
- Process target: >= 90% weekly session compliance

## Core System
1. Plan quality:
- Weekly plan is finalized before Sunday 20:00.
- Every key session has objective, intensity target, and KPI.

2. Execution quality:
- AM protocol starts within 5 minutes of alarm.
- PM session starts on planned time window.
- No skipping without immediate reschedule rule.

3. Feedback quality:
- Daily check-in every evening.
- Weekly review every Sunday.
- Weekly update file generated and completed.

4. Adaptation quality:
- Load adjusted based on compliance + recovery + performance trend.
- Deload inserted every 4th week unless race week.

## Weekly Success Score (0-100)
- Session completion (40 points)
- Key session quality (20 points)
- Nutrition adherence (15 points)
- Sleep consistency (15 points)
- Check-in completion (10 points)

## Score-Based Actions
- 90-100: Progress load as planned.
- 80-89: Hold load, improve process friction.
- 70-79: Reduce complexity, preserve key sessions.
- <70: Reset week, focus on habit integrity.

## Critical Constraints
- Protect sleep timing consistency.
- Keep easy sessions easy.
- Fuel key sessions correctly.
- Never stack hard days from missed training spillover.
