# Intervention Ladder (When Execution Breaks)

## Trigger Categories
1. Compliance trigger:
- Missed >= 2 sessions in 7 days

2. Recovery trigger:
- HRV depressed 3+ days or RHR elevated 3+ days

3. Performance trigger:
- Two consecutive key sessions below target quality

4. Nutrition trigger:
- Carb under-fueling on 2+ key sessions/week

## Ladder
### Level 1 (Immediate, same day)
- Simplify next 48h to only critical sessions.
- Move non-critical volume to recovery work.
- Recommit AM launch protocol.

### Level 2 (Within week)
- Reduce weekly volume by 10-20%.
- Keep one key intensity per modality.
- Add one extra recovery block.

### Level 3 (Weekly reset)
- Deload week with 20-30% volume reduction.
- Rebuild session timing discipline.
- Remove optional accessories and complexity.

### Level 4 (Escalation)
- If poor trend persists 2+ weeks: reassess goals/timeline and stress load.
- Consider medical review if abnormal fatigue signals persist.

## Return-to-Progress Criteria
- 7 consecutive days with:
- >= 90% session completion
- stable sleep timing
- recovery markers normalized
- key session quality restored
